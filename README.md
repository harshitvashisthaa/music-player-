# Spotify Clone - Web Music Player 🎵

A fully responsive, web-based music player featuring a sleek user interface inspired by Spotify. This project demonstrates front-end development skills by integrating audio controls and dynamic DOM manipulation.

## 🚀 Features

*   **Interactive Audio Controls:** Play, pause, skip to the next track, or go back to the previous one seamlessly.
*   **Dynamic UI:** Displays the current song title, artist, and total duration. 
*   **Progress & Volume:** Includes a functional progress bar to track song position and volume controls for the perfect listening experience.
*   **Demo Playlist:** Pre-loaded with a customized playlist (featuring hits from artists like Karan Aujla) to demonstrate the player's capabilities.
*   **Spotify-Inspired Design:** A modern, dark-themed interface built from scratch to mimic the look and feel of the popular streaming platform.

## 🛠️ Technologies Used

*   **HTML5:** Structured the player's layout, controls, and tracklist.
*   **CSS3:** Designed the dark theme, hover states, layout grids, and responsive design for mobile and desktop screens.
*   **Vanilla JavaScript:** Handled the core logic for the HTML5 `<audio>` API, updating the progress bar, and managing the playlist array.
